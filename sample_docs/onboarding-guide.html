Welcome to the data platform

New engineers get read access to the analytics warehouse on day one. Write access to production schemas requires completing the data governance training.

Local setup

Install Python 3.11, Docker and the cloud CLI. Clone the platform repository and run the bootstrap script to configure credentials through single sign-on.

Code review

Every pipeline change needs one approving review and passing CI. Changes to shared models also need sign-off from the model owner listed in the catalog.
